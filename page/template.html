Where a human (or a real browser) was needed

    $human

What the agent code enforces

  • Evidence must be a page the agent opened. A submission that cites a URL it never fetched is rejected and sent back (tested in tests/).
  • Closed answer sets. The output schema is the rubric, so there is no free text for auth, access or verdict.
  • Self-repair, then escalate. A rule violation gets two repair attempts. After that the row is saved as low confidence and routed to a human.
  • Composio-native tools. Web search and page reading come from Composio tools (TAVILY_SEARCH, TAVILY_EXTRACT, FIRECRAWL_SCRAPE) through the Composio SDK, with Claude as the model.
How this run was produced. For this submission, Claude acted as the research agent. It used web search, page fetch and a real browser pane, with the rubric, validators and scorers in this repo as its checks. agent/research.py packages the same loop as a headless pipeline on Composio's SDK. The pipeline is unit-tested offline with a scripted model. It needs COMPOSIO_API_KEY and ANTHROPIC_API_KEY to run live.

Loop B also made one row worse before the audit fixed it: Waterfall.io moved from "trial, ready" to "partner, blocked", then to the correct "approval, friction". Loops can regress, and that is why the audit exists.

Rules the audit added, applied to all 100 rows

  • A free plan is not a free API. Read the plan table's API row. This changed Help Scout, Freshdesk and Smartsheet to trial.
  • A docs-search MCP is not an official MCP. It cannot act on the account. This changed Twilio; Mailchimp and Vonage were already right.
  • If OAuth exists but isn't primary, say why. Rule 11 in the validator. This changed Netlify, Vercel, Supabase and Sentry to OAuth, and 17 apps now carry a written reason.

5Proof: run it yourself

The repo holds the agent, the verifiers, the data from every pass, and a GitHub Action you can trigger from the Actions tab.

Verify everything offline (no keys needed)

git clone $repo
cd composio-app-research
pip install -r requirements.txt
python -m pytest -q                 # 8 tests, incl. the agent loop
python -m verify.validate final     # 11 rules on all 100 rows
python -m verify.score              # reproduces every accuracy number
python page/build.py                # rebuilds this page from data/

Run the research agent live (Composio + Claude)

export COMPOSIO_API_KEY=...  ANTHROPIC_API_KEY=...
# connect Tavily and/or Firecrawl for your user in Composio
python -m agent.run --only 41 --user-id me      # one app
python -m agent.run --ids 1-100 --out agent_run # the full list
python -m verify.score agent_run                # grade it vs gold

Runnable trigger: GitHub Action "Research one app" CI: verify data
