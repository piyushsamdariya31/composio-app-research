What 100 apps have in common

Six findings, each computed from the dataset below, so the claims and the table can't drift apart.

71/100

can be built as a toolkit today

22 more are buildable once a review, paid plan or key request is cleared. Only 7 are blocked by a partnership or a missing public API.

OAuth2

is the most common primary auth, but keys are everywhere

OAuth2 is the best primary method for 50 apps; a static API key or token for 45. 74 apps offer a key or token and 67 offer OAuth2. 45 offer both, so toolkits need first-class key support, not just OAuth.

72/100

give developers credentials without asking anyone

Developer, Infra and Data platforms and Productivity and Project Management are 10/10 self-serve. The gated categories: Marketing, Ads, Email and Social 5/10; Ecommerce 5/10; AI, Research and Media-native 5/10; Finance and Fintech 5/10. Ads platforms gate on app review, fintech on account approval or partnership, AI-native apps on paid plans.

11 + 11

app review and paid plans tie as the top blocker

Partnership gates are rarer (6) and sit with enterprise and fintech apps: DealCloud, Pylon, Gladly, Salesforce Commerce Cloud, Paygent Connect, PitchBook.

9

easy wins: ready now and not yet a full Composio toolkit

Facts that changed in 2025–26, which a model's memory gets wrong

  • Shopify Admin-created custom apps (static tokens) can no longer be created; Storefront MCP was removed in favour of Shop MCP / UCP.
  • Salesforce Connected-app creation restricted from Spring '26; hosted MCP servers went GA in April 2026 for Enterprise Edition and up.
  • Zendesk API tokens are marked deprecated; OAuth is the supported method.
  • Xero 2026 developer pricing: free Starter tier capped at 5 connections, paid tiers above.
  • fanbasis Rebranded to Commas; APIs offered to enterprises through sales.
  • Amazon SP-API Docs moved to developer-docs.amazon.

That's why research has to run against live docs. The memory-only first pass was weakest on MCP (6 of 20 sampled answers wrong) and on access (3 wrong).

6 · Honest limits

What defeated the agent

  • Two rows stay low-confidence: Paygent Connect (product page not found; NMI researched instead) and fanbasis/Commas (no public API docs).
  • Zendesk's MCP status rests on a third-party report (tldv.io) plus the absence of any vendor page. The vendor has not published a ticket MCP.
  • Mailchimp's free-plan API access and Fathom's free-plan API access were not confirmed in a plan table. They are marked free because any account can create a key.
  • 'Community MCP' versus 'none found' is weakly evidenced, so the audit scores MCP only as official or not.
  • Pass 1 cited an Otter help-center article with an invented id (a 404). Loop C found the real article. Pass 1 also used the brief's iPayX docs link, which is a 404 too.
  • The audit sample is 20 apps (seed 20261123) and the holdout is 8 apps. A perfect 48 of 48 fields still allows a true field accuracy as low as 92.6% (Wilson 95% lower bound), and the holdout skews toward well-documented apps.
